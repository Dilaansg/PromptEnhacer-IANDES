# Prompt Enhacer - IANDES

**Local, Machine Learning-Powered Prompt Engineering Assistant**

[![Version](https://img.shields.io/badge/version-6.0.0-blue.svg)](#)
[![Manifest](https://img.shields.io/badge/Manifest-V3-green.svg)](#)
[![Model](https://img.shields.io/badge/ONNX-multilingual--e5--small-orange.svg)](#)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.4-3178c6.svg)](#)

A Chrome Extension (Manifest V3) that seamlessly integrates with ChatGPT, Claude, and Gemini to analyze, structure, and optimize your prompts using a local AI pipeline and semantic embeddings.

</div>

---

## 📖 English

### 🚀 Features

| Feature | Description |
|---------|-------------|
| **Prompt Optimization** | Transform basic prompts into detailed, structured instructions |
| **100% Offline** | All processing runs locally using ONNX Runtime — no internet required |
| **Multi-Platform** | Works on ChatGPT, Claude, and Gemini |
| **3-Layer Pipeline** | Semantic Classification → Adaptive Questions → SuperPrompt Generation |
| **95+ Languages** | Supports Spanish, English, French, German, Chinese, and more |
| **Interactive Side Panel** | Compare original vs. optimized prompts, answer guided questions |
| **Total Privacy** | Your data never leaves your browser |

### 📦 Installation

#### From Chrome Web Store (soon)

*Coming soon to the Chrome Web Store.*

#### Manual Installation (Developer Mode)

```bash
# Clone the repository
git clone https://github.com/Dilaansg/PromptEnhacer-IANDES.git
cd PromptEnhacer-IANDES

# Install dependencies
npm install

# Build the extension
npm run build
```

1. Open `chrome://extensions/` in Chrome
2. Enable **"Developer mode"** (top right corner)
3. Click **"Load unpacked extension"**
4. Select the `dist/` folder generated by the build

### 🧠 Architecture

```
                     ChatGPT / Claude / Gemini
                              │
                              ▼
                    ┌─────────────────┐
                    │  Content Script  │
                    │  (Floating Button)│
                    └────────┬─────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │  Service Worker │
                    │  ┌────────────┐ │
                    │  │  ONNX      │ │
                    │  │ Embedding  │ │
                    │  │ Engine     │ │
                    │  └─────┬──────┘ │
                    │  ┌─────▼──────┐ │
                    │  │  Layer A   │ │
                    │  │   Classify │ │
                    │  ├────────────┤ │
                    │  │  Layer B   │ │
                    │  │  Questions │ │
                    │  ├────────────┤ │
                    │  │  Layer C   │ │
                    │  │ SuperPrompt│ │
                    │  └────────────┘ │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │   Side Panel    │
                    │  Comparison     │
                    │  Questions      │
                    │  Metrics        │
                    └─────────────────┘
```
#### 3-Layer Pipeline

| Layer | Function | Output |
|-------|----------|--------|
| **A — Classification** | Classifies prompt by type, intent, and domain | Structured prompt profile |
| **B — Questions** | Generates adaptive questions when ambiguity is detected | Additional context from user |
| **C — Generation** | Builds the optimized SuperPrompt | Production-ready prompt |
