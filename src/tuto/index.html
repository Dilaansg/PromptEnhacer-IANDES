1

¿Qué es un prompt?

Un prompt es la instrucción que envías a un modelo de IA. La calidad del output depende directamente de la calidad del input — un prompt vago produce respuestas vagas; un prompt de ingeniería produce resultados predecibles y precisos.

prompt débil vs. prompt de ingeniería
// ✗ Prompt débil — resultado impredecible
"Explica la revolución industrial"

// ✓ Prompt de ingeniería — resultado controlado
ROL → Historiador experto, análisis crítico
TAREA → Revolución industrial: causas + mecanismos
NIVEL → Intermedio, asume conocimiento básico
FORMATO → Tres secciones, terminología precisa
2

Anatomía de un prompt

Rol

Persona / Rol

Define quién es el modelo. "Actúa como un experto en…" establece tono, vocabulario y nivel de profundidad.

Contexto

Contexto

Información de fondo que el modelo necesita. Cuanto más relevante sea, más precisa será la respuesta.

Tarea

Instrucción principal

El verbo de acción: explicar, resumir, generar, comparar. Sé específico sobre qué quieres que produzca.

Formato

Formato de salida

Cómo quieres la respuesta: lista, tabla, párrafos, JSON, código. Evita ambigüedades de estructura.

Super-Prompt anotado

Super-Prompt ✨ Mejorado
Actúa como un tutor paciente especializado en historia económica. El estudiante tiene conocimiento básico pero necesita reforzar los mecanismos subyacentes. Explica la Revolución Industrial desde sus causas estructurales, cubriendo mecanismos y aplicaciones prácticas. Usa terminología precisa, verifica comprensión con preguntas al final y adapta el nivel si el estudiante lo solicita.

5

Técnicas esenciales

🎭

Role Prompting Base

Asigna una persona al modelo. "Eres un abogado mercantil con 20 años de experiencia…" mejora la pertinencia y profundidad de la respuesta inmediatamente.

🔗

Chain of Thought Base

Pide al modelo que piense paso a paso. "Razona antes de responder" o "Muestra tu proceso" reduce errores en tareas complejas de razonamiento y matemáticas.

🎯

Few-Shot Prompting Avanzado

Incluye 2–5 ejemplos del formato esperado antes de tu pregunta. El modelo aprende el patrón y lo replica con alta precisión en la respuesta final.

🚧

Negative Prompting Avanzado

Especifica qué NO quieres. "Sin introducciones genéricas", "Sin mencionar X", "Evita tono académico". Los límites negativos acotan el espacio de respuestas posibles.

🔄

Iteración y Refinamiento Base

Los mejores prompts se construyen en varias rondas. Evalúa el output, identifica qué falta y añade constraints hasta lograr el resultado deseado.

6

El pipeline de IAndes

Layer A
Captura del prompt original. Recibe y analiza la intención del usuario, detecta el dominio y el nivel de complejidad de la solicitud.
Layer B
Enriquecimiento semántico. Añade contexto, rol, restricciones y formato. Transforma el prompt débil en un super-prompt estructurado.
Layer C
Validación y entrega. Verifica coherencia, aplica overrides del usuario y entrega el prompt final optimizado al modelo.
7

Tips de referencia rápida

📐

Sé específico

Longitud, tono, audiencia objetivo. La vaguedad produce outputs genéricos.

🧩

Divide la tarea

Tareas complejas funcionan mejor divididas en sub-prompts secuenciales.

🔍

Pide verificación

"¿Entendiste correctamente?" o "Resume tu plan antes de ejecutar."

📝

Usa ejemplos

Un ejemplo vale más que tres párrafos de descripción abstracta.

🎛️

Controla el nivel

Indica el nivel de expertise esperado: básico, intermedio, experto.

🔁

Itera siempre

El primer prompt rara vez es el mejor. Refina con base en el output.
